# 포켓몬 트레이너 카드 — 1~4인

트레이너 카드를 혼자서도, 넷이서도 만드는 도구입니다.
HTML 파일 하나 + 스프라이트시트 두 장으로 돌아가고, 서버도 빌드도 필요 없습니다.

`index.html` 을 브라우저로 열면 바로 씁니다.

> 1인용만 쓰실 거면 [pokemon-trainer-card](https://github.com/hihipako/pokemon-trainer-card) 도 있습니다.
> 이 저장소는 그 카드를 그대로 품고 2~4인을 더한 것입니다.

---

## 인원에 따라 달라지는 것

| 인원 | 카드 | 배치 |
| --- | --- | --- |
| 1인 | 1120×700 | 글·막대 ǀ 사진 — 기존 카드와 같습니다 |
| 2인 | 1320×560 | A ǀ 단체샷 ǀ B |
| 3인 | 1320×1072 | A·B ǀ 단체샷 ǀ C |
| 4인 | 1320×1072 | A·B ǀ 단체샷 ǀ C·D |

**사람 한 칸**은 이름·신분 / 한 줄 대사 / 설명 / 엔트리 막대 6개로 이루어지고,
2인 이상이면 막대 옆에 **단독샷** 칸이 생깁니다. 가운데는 **단체샷** 입니다.

---

## 할 수 있는 것

- 사람마다 이름 · 신분 / 한 줄 대사 / 설명 — 넣고 싶은 것만 켜서 씁니다
- 신분은 **트레이너 칭호 215종** 목록에서 고르거나 직접 씁니다
- 단체샷과 단독샷 모두 **칸 비율에 맞춰 자르기** — 끌어서 위치, 슬라이더로 크기
- **엔트리 도트는 사람마다 여섯 개가 한 덩어리로 움직입니다.** 단체샷 위 어디로든 —
  2인은 좌·우, 3~4인은 네 귀퉁이에서 시작합니다. 도트를 누르면 그 칸이 열려요
- 스티커 · 로고 이미지를 얹어 카드 어디로든 배치
- 포켓몬 **1530종** — 리전폼 · 메가 · 거다이맥스는 물론 트리토돈 동쪽바다 같은 겉모습 폼까지
- 이름 · 영문명 · 도감번호 · **초성**(`ㄴㅍㅇ` → 님피아) 검색, **타입으로 걸러내기**
- 엔트리마다 닉네임 · 사이즈 9단계 · 성별 · 이로치 · **증표 칭호 98종** · **리본 101종**
- 배경색 자유, 글자색은 배경 밝기에 맞춰 자동 반전
- 카드를 PNG로 내보내기, 카드 코드로 남에게 넘기기

## 직접 빌드하기

```bash
npm install
npm run build     # src/template.html + data/payload.json → index.html
npm test          # 가상 브라우저로 화면을 눌러보는 점검 (42항목)
npm start         # http://localhost:8080
```

포켓몬 데이터와 스프라이트시트는
[pokemon-trainer-card](https://github.com/hihipako/pokemon-trainer-card) 에서 만든 것을 가져와 씁니다.
포켓몬이 추가되면 그쪽에서 `npm run build` 를 돌린 뒤
`data/payload.json` 과 `sheet-*.webp` 를 이리로 복사하면 됩니다.

```
index.html            바로 열 수 있는 완성본 (데이터가 안에 박혀 있음)
sheet-normal.webp     도트 스프라이트시트 — 일반  3072×4608, 무손실
sheet-shiny.webp      도트 스프라이트시트 — 이로치
src/template.html     데이터가 빠진 원본. 화면을 고칠 때는 이 파일을 고칩니다
data/payload.json     포켓몬 1530종 · 증표 · 리본 · 트레이너 칭호
tools/build.js        빌드
tools/smoke.js        가상 브라우저 점검
tools/serve.js        의존성 없는 정적 서버
```
